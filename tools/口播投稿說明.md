# 口播投稿到提詞庫（給「口播文案專案」的 Claude 看）

當使用者要求「**把這篇投稿到提詞庫**」「**加進提詞庫**」「**同步到提詞庫**」時，照以下步驟做：

## 步驟

1. 把這篇口播整理成 JSON，**只有 `title` 和 `voiceover` 必填**，其餘選填。
   - 欄位格式見同資料夾的 `口播範本.json`
   - `platforms` 五個鍵：`tiktok` / `youtube` / `ig` / `threads` / `fb`
   - `factCheck`：`pending`（待查證）/ `verified`（已查證）/ `na`（無需查證），預設 `pending`
   - `source` 要是完整 `https://` 連結（追蹤參數可清掉）

2. 把 JSON 寫到一個暫存檔，例如 `C:/Users/aass/Desktop/Code/_vo_inbox.json`
   - 單篇用物件 `{...}`，多篇用陣列 `[{...},{...}]`

3. 執行投稿腳本（會自動加進資料庫並推送到 GitHub）：
   ```bash
   node "C:/Users/aass/Desktop/Code/prompt-library/tools/add-voiceover.js" "C:/Users/aass/Desktop/Code/_vo_inbox.json"
   ```

4. 看到 `✓ 已推送到 GitHub` 就完成了，刪掉暫存檔。
   提詞庫網頁約 1 分鐘後自動更新，新口播會出現在「🎙️ 口播」分類最上面、標記為「⬜ 待口播」。

## 注意

- 腳本會自動補齊 id、時間、分類（voiceover）等欄位，**不要自己塞這些**。
- 腳本會自動 `git pull --rebase` 再 push，避免覆蓋雲端資料。
- 若 `factCheck` 設 `verified`，請確定真的查核過（使用者是台南房仲，數據錯誤會影響專業形象）。
